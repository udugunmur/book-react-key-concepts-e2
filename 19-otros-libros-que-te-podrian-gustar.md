# Parte 2: Construcción de Aplicaciones React Complejas

## Otros Libros que te Podrían Gustar

Si disfrutaste de este libro, tal vez te interesen estos otros títulos de Packt:

---

### Sección 1: Learning Angular

**Autor:** Aristeidis Bampakos  
**ISBN:** 9781835087480

- Utiliza la CLI de Angular para generar la estructura, compilar y desplegar nuevas aplicaciones de Angular.
- Crea aplicaciones de Angular utilizando APIs independientes (*standalone APIs*).
- Construye componentes enriquecidos con la sintaxis de plantillas de Angular.
- Aplica patrones de reactividad con la biblioteca RxJS y Signals.
- Diseña interfaces de usuario atractivas utilizando Angular Material.
- Crea servicios de datos HTTP para acceder a APIs y proporcionar datos a los componentes.
- Mejora tus habilidades de depuración y manejo de errores durante el tiempo de ejecución y desarrollo.
- Optimiza el rendimiento de las aplicaciones con técnicas de SSR e hidratación.

---

### Sección 2: Responsive Web Design with HTML5 and CSS

**Autor:** Ben Frain  
**ISBN:** 9781803242712

- Utiliza media queries, incluyendo detección para táctil/ratón y preferencia de color.
- Aprende semántica de HTML y crea marcado accesible.
- Facilita diferentes imágenes según el tamaño o la resolución de la pantalla.
- Escribe las últimas funciones de color, mezcla colores y elige los más accesibles.
- Utiliza SVGs en los diseños para proporcionar imágenes independientes de la resolución.
- Crea y utiliza propiedades personalizadas de CSS (*custom properties*), aprovechando las nuevas funciones de CSS, incluidas `clamp`, `min` y `max`.
- Agrega validación y elementos de interfaz a los formularios HTML.
- Mejora los elementos de la interfaz con filtros, sombras y animaciones.

---

### Sección 3: Mastering Node.js Web Development

**Autor:** Adam Freeman  
**ISBN:** 9781804615072

- Procesa solicitudes HTTP y realiza operaciones con archivos.
- Crea servicios web RESTful que puedan ser consumidos por aplicaciones del lado del cliente.
- Trabaja con aplicaciones de servidor que atienden a clientes JavaScript, como React y Angular.
- Aprovecha Node.js para trabajar con bases de datos populares.
- Aplica conocimientos prácticos mediante la construcción del proyecto SportsStore.
- Autentica usuarios y autoriza el acceso a las funciones de la aplicación.
